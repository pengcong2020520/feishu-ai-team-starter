# 开放团队包搭建提示词

把下面这段连同本仓库链接交给 Coding Agent：

> 请读取 AGENTS.md、docs/版本导航.md 和 docs/AI团队包规范.md。先确认我要的是原来的网页团队，还是可安装他人团队包的协作环境；已明确的选择不要重复问。需要多个飞书项目群时沿用领航版，保留既有机器人和工作区。
>
> 按 node setup.mjs 的下一步把本机服务跑通，不自行写扫码或建群脚本。已有机器人按标准命令增补权限。然后执行 node scripts/team-pack.mjs init，安装筑页、观澜和文枢三支团队。说明 Newtype 是固定上游版本的独立来源适配包，许可保留，不将其标为 MIT。
>
> 打开 /teams。先选择我想用的团队；网页团队复用已创建机器人，其他团队逐个绑定可复用机器人，缺少时才运行 team-pack.mjs bots 的扫码流程。每个角色对应独立机器人，不要只换卡片标题冒充。未扫码前也可以先在本机验证。
>
> 在人员名册设置真实操作者和职责，在新项目选择成员、关口确认人、团队和目标。用两种团队的独立项目验证上下文、会话、文件和确认卡隔离；验证必做任务、顺序与允许的并行。不要改变作者的协作规则。验证代码和模型交付分开记录，不把替身测试说成真实飞书。
>
> 若我要导入他人包，使用团队包工具校验并安装固定提交链接或导出文件；若我要分享自己的团队，使用 skills/team-packager/SKILL.md，保留原规则、许可和来源，实际完成导出与干净目录重新安装，默认不上传 GitHub。
