# 开放 AI 团队包：本机验收记录

日期：2026-11-27。范围：本机实现与运行验证；本轮尚未推送 GitHub。标准见 [AI 团队包规范](AI团队包规范.md)，安装步骤见 [开放团队包提示词](prompts/ecosystem.md)。

## 交付结果

- 平台按清单加载角色提示词、Skill、协作 Skill、工作流、工作区模板和交付契约。第四个自定义团队已通过导出、干净安装和真实模型执行，不需要修改平台代码。
- 初始安装筑页（网页）、观澜（投研）、文枢（Newtype 内容）三套团队。角色数分别为 3、6、8，仍共用 Agent SDK 和服务总并发名额。
- 项目锁定包版本与内容摘要；会话按项目路径和角色分开。固定流程、条件分支、按目标选择任务、依赖和并行、人工确认、打回、停下、重试均由通用编排执行。
- 工作台新增 `/teams`，可以选团队建项目、分配成员与确认人、看协作计划、讨论及交付物。旧网页项目仍沿用原流程。
- 提供 [team-packager Skill](../skills/team-packager/SKILL.md) 及 validate/export/install/verify-export 命令。导出使用文件白名单，排除凭据、身份、项目状态和会话。

## 对抗审查

本轮按下列失败与攻击路径检查，并将关键行为纳入测试：

| 方向 | 检查与修正 |
| --- | --- |
| 包越权 | 拒绝未声明角色、技能、工具、写目录及输出；拒绝路径穿越、软链接、保留字段、已知凭据和身份材料；禁止安装脚本 |
| 调度越权 | 拒绝虚构任务、漏必做任务、环和缺失依赖；最终汇总必须等待选中任务；禁止同角色会话或重叠写目录并行 |
| 人员与卡片 | 身份由服务端取得；错误确认人、跨项目和过期卡片被拒绝；自定义关口进入职责匹配；建项确认只认发起人且防重复 |
| 上下文隔离 | 项目路径与角色隔离会话；只读问答隔离临时会话；本轮建项前讨论随项目迁移，不携带上一项目讨论 |
| 故障恢复 | 并行任务逐个落盘，重试只补未完成任务；服务重启不自动继续；修复 SDK 启动前收到停下指令的竞态 |
| 外部读取 | HTTPS 公网来源、逐跳重定向与固定 DNS 地址；拒绝内网和保留网段；Fake-IP 环境通过固定 DoH 核实公网地址，未直接放行保留地址 |
| 复现与接入 | 包摘要使用确定排序；扫码后中断可补写绑定而不重复建机器人；服务健康检测支持动态角色数量 |
| 展示 | 产物文本使用 textContent，HTML 产物使用受限 iframe；卡片姓名与真正的飞书提醒分开处理 |

Grok CLI 的两次独立审查请求分别在 300 秒、180 秒超时，没有返回审查结论。因此本记录中的对抗审查是实施 Agent 自审加自动化检查，**不声称 Grok 独立审查通过**。
